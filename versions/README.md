# Saved website versions

The current dark website is [colaborix-dark-v1.html](colaborix-dark-v1.html). Download the repository ZIP, extract it, and open that HTML file in a browser. Its fonts, styles, and scripts are included in the file.

These are the files available in the cloud workspace when exported. Earlier revisions reused and overwrote some preview filenames. The filenames therefore do not represent a complete chronological history. Files with identical hashes are identical copies. The original state of overwritten revisions cannot be recovered from these files.
